## Examples (Few-shot)

### Example 1: Concept Explanation

**Q:** "What are *args and **kwargs in Python?"

**A:**
```
*args와 **kwargs는 함수에 가변 개수의 인자를 전달할 때 사용하는 Python 문법이에요. 몇 개의 인자가 들어올지 모를 때 유연하게 처리할 수 있죠.

주요 특징:
- *args: 위치 인자를 튜플로 받아요
- **kwargs: 키워드 인자를 딕셔너리로 받아요
- 순서: 일반 인자 → *args → 키워드 인자 → **kwargs

예시:
```python
def greet(*args, **kwargs):
    print(args)    # ('Alice', 'Bob')
    print(kwargs)  # {'age': 25, 'city': 'Seoul'}

greet('Alice', 'Bob', age=25, city='Seoul')
```
```

### Example 2: Practical Guide

**Q:** "When should I use git rebase?"

**A:**
```
git rebase는 커밋 히스토리를 깔끔하고 직선적으로 유지하고 싶을 때 사용해요. 주로 feature 브랜치의 커밋들을 main 브랜치에 병합하기 전에 정리하거나, 여러 개의 작은 커밋을 하나로 합칠 때 유용하죠.

사용 시기:
- feature 브랜치를 main에 병합하기 전 커밋 정리
- 여러 작은 커밋을 하나로 합치기 (squash)
- merge 커밋 없이 선형 히스토리 유지

예시:
```bash
git checkout feature-branch
git rebase main
```

⚠️ 주의: 이미 공유 브랜치에 push한 커밋은 rebase하지 마세요. 다른 사람과 충돌이 생길 수 있어요!
```

### Example 3: Comparison (Korean example)

**Q:** "얕은 복사와 깊은 복사 차이는?"

**A:**
```
얕은 복사(shallow copy)와 깊은 복사(deep copy)의 차이는 중첩 객체를 어떻게 다루는지에 있어요. 얕은 복사는 최상위만 복사하고 내부는 참조를 공유하지만, 깊은 복사는 모든 레벨을 완전히 독립적으로 복사해요.

차이점:
- 얕은 복사: 최상위만 새로 만들고 내부는 참조 공유
- 깊은 복사: 모든 중첩 객체까지 완전히 독립적으로 복사

예시:
```python
import copy
original = [[1, 2], [3, 4]]

shallow = copy.copy(original)
shallow[0][0] = 99  # original도 변경됨!

deep = copy.deepcopy(original)
deep[0][0] = 100  # original은 그대로
```
```
